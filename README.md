
# API de Gerenciamento de Professores

API REST desenvolvida com Node.js e Express para gerenciar
professores, suas turmas e disciplinas.

## Tecnologias utilizadas

- Node.js
- Express
- JavaScript
- Postman ou Thunder Client

## Funcionalidades

- Listar professores
- Buscar professor por ID
- Listar turmas de um professor
- Atualizar dados de um professor
- Adicionar turma a um professor
- Filtrar professores por departamento
- Remover professor

## Como executar

1. Instale o Node.js.
2. Clone este repositório.
3. Abra o terminal na pasta do projeto.
4. Execute `npm install`.
5. Execute `npm start`.
6. Acesse `http://localhost:3000/professores`.

## Armazenamento

Os dados são armazenados em arrays e objetos JavaScript
na memória. Os dados são reiniciados quando o servidor
é encerrado ou reiniciado.

## Testes

As capturas das requisições e respostas estão na pasta `prints`.
